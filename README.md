# Health & 100-Day Goal Calculator

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://health-calculator-predictor.streamlit.app/)

A simple web application built with Python and Streamlit to calculate body composition metrics, BMI, body fat percentage, and a 100-day nutritional strategy.
